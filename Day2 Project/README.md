## 🚀 Features

* Add tasks
* Delete tasks
* Mark tasks as complete
* Persistent storage (tasks saved even after refresh)
* Responsive and clean UI

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript (DOM Manipulation, Events)
* LocalStorage (for persistence)

## 🧠 What I Learned

(IMPORTANT – recruiters read this)

* Handling dynamic DOM updates
* Managing user input and events
* Avoiding redundant event listeners
* Implementing browser storage for persistence

---

## ⚙️ How It Works

* User enters a task → stored in an array
* Tasks are rendered dynamically in the UI
* Each task has options to complete or delete
* Data is saved in localStorage
