# 🌙 MoonMood – Smart Theme Toggle App

MoonMood is a responsive web app that allows users to switch between light and dark themes with smooth animations and persistent user preferences.

## 🚀 Features
- Toggle between Day & Night themes
- Saves theme preference using localStorage
- Auto-detects system dark mode
- Smooth UI transitions
- Responsive design

## 🛠️ Tech Stack
- HTML
- CSS (Flexbox, transitions)
- JavaScript (DOM, events, localStorage)

## 📌 What I Learned
- DOM manipulation best practices
- Event handling using addEventListener
- State persistence in browser
- UI/UX improvements with CSS
